## Cách upload lên GitHub Pages

1. Tạo repository mới trên GitHub.
2. Upload toàn bộ file trong thư mục này lên repository.
3. Vào Settings → Pages.
4. Chọn Branch: main, Folder: /root.
5. Bấm Save.
6. Nếu dùng domain riêng, thêm file `CNAME` chứa domain của bạn.
